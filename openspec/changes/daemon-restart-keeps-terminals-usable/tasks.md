## 1. Scratch files (must land before the unit change)

- [x] 1.1 Add `packages/server-core/src/scratchDirectory.ts`. On POSIX it owns `<tmpdir>/terminay-<uid>`: it creates the root with mode 0700, checks with `lstat` before each use that the root is a directory, not a symlink, owned by this uid, with no group or other bits, and opens files with `O_CREAT|O_EXCL|O_NOFOLLOW`, mode 0600.
