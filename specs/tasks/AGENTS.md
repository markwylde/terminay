# AGENTS — active implementation tasks

This folder contains only work that remains to be implemented.

- Prefix filenames with the next integer (`1-…`, `2-…`) and keep the task small
  enough to deliver and verify.
- Link the governing feature spec, state what is not implemented, and finish
  with explicit acceptance checks and a definition of done.
- Move the file to `../tasks_completed/` once the work is complete; do not use
  this folder as a retrospective archive.
